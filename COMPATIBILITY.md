# Compatiblilty List

This is a list of all vehicles that have been tested, with any relevent notes listed as well.

## Compatible Vehicles

### Volkswagen

- 2015-2018 (Mk7) Golf
- 2015-2018 (Mk7) Golf Alltrack
- 2015-2018 (Mk7) GTI
- 2015-2018 (Mk7) Golf R
- 2019-2021 (Mk7.5) Golf
- 2019-2021 (Mk7.5) Golf Alltrack
- 2019-2021 (Mk7.5) GTI
- 2019-2021 (Mk7.5) Golf R  
- 2012-2018 (Mk6) Jetta GLI

#### Listed below are vehicles that *should* work, but not tested

- 2012-2018 (Mk6) Jetta, All trim levels
- 2019- (Mk7) Jetta, All trim levels
- 2022- (Mk8) Golf, All trim levels

Basically, any vehicle built on the MQB or PQ35 platform with CANbus on OBD2.

### Audi

- 2015-2021 (8V) Audi RS3 (See table below)

#### Listed below are vehicles that *should* work, but not tested

- 2015-2021 (8V) Audi A3
- 2015-2021 (8V) Audi S3
